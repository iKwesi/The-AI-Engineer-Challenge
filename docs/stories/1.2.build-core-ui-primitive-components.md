### Component Specifications
[Source: architecture/section-4-component-standards.md]

**Button Component Requirements:**
- Must follow TypeScript interface pattern: `ButtonProps`
- Required props: `children`, `onClick`
- Optional props: `variant` ('primary' | 'secondary'), `disabled` (boolean)
- Base classes: `px-4 py-2 rounded-lg font-semibold transition-colors`
- Primary variant: `bg-accent text-accent-text hover:bg-accent-hover`
- Secondary variant: `bg-transparent border border-border text-text-primary hover:bg-gray-100`
- Disabled state: `opacity-50 cursor-not-allowed`

**Input Component Requirements:**
- Must support text and password input types
- Error state styling for form validation
- Placeholder and label support
- Consistent styling with theme colors
- Focus states using accent colors

**Card Component Requirements:**
- Container component for content grouping
- Use `bg-container` background color
- Apply `shadow-soft` from theme configuration
- Proper padding and border radius
- Support for children content

### Theme Configuration
