## Dev Notes

### Project Structure Requirements
[Source: architecture/section-3-project-structure.md]

The new directory structure must follow this exact layout:
```
frontend/src/
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
│
├── components/
│   ├── features/
│   │   └── chat/
│   │       └── ProfessionalChatInterface.tsx  # The main, feature-specific component
│   │
│   └── ui/
│       ├── Button.tsx                       # Reusable, styled button
│       ├── Input.tsx                        # Reusable, styled input
│       └── Card.tsx                         # Reusable container component
│
├── hooks/
│   └── useChat.ts
│
├── services/
│   └── chatService.ts
│
├── types/
│   └── index.ts
│
└── utils/
    └── index.ts                           # Utility functions (e.g., classname helpers)
```

This structure provides clear separation between general-purpose UI elements (`ui`) and feature-specific compositions (`features`).

### Theme Configuration Requirements
[Source: architecture/section-8-styling-guidelines.md]

The `tailwind.config.js` must be updated with this exact configuration:
```javascript
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [ "./src/**/*.{js,ts,jsx,tsx,mdx}" ],
  theme: {
    extend: {
      colors: {
        'background': '#F8F9FA',
        'text-primary': '#212529',
        'accent': {
          DEFAULT: '#00796B', // Teal
          'hover': '#00695C',
          'text': '#FFFFFF',
        },
        'container': '#FFFFFF',
        'border': '#E9ECEF',
        'assistant-bubble': '#F1F3F5',
      },
      boxShadow: {
        'soft': '0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1)',
      }
    },
  },
  plugins: [ require('@tailwindcss/forms') ],
};
```
